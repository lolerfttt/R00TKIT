# R00TKIT

Минималистичная idle-игра про взлом: чёрный экран, зелёный текст, всё управление — командами в консоли. `prod by 3percent · v2.0`.

## Запуск

Открыть `R00TKIT.html` в браузере. Интернет и установка зависимостей не нужны. Папку `r00tkit_files` нужно переносить вместе с `R00TKIT.html` — в ней лежат стили, скрипты и звуки.

При первом запуске сначала открывается стартовый экран: играет трек меню, есть ползунок громкости и кнопка «продолжить». Только после неё игра просит ник. Часть символов автоматически превращается в leet (`peppy` → `p3ppy`, `nevercry` → `n3vercr9`), иногда добавляется `_1337` или `xx_..._xx`. Ник запоминается отдельно от прогресса и переживает `reset confirm`. После этого проигрывается интро входа: логин — ваш ник, пароль звёздочками, проверка ключей.

При следующих открытиях стартовый экран уже не показывается: ник известен, интро запускается сразу. Любая клавиша или клик пропускают его.

При первом запуске и после `reset confirm` включается короткое обучение: взлом, магазин, покупка процессора и рига, статус. В конце — тревога с таймером: нужно успеть стереть данные командой `wipe`. После успеха терминал растворяется снизу вверх за 3 секунды, прогресс обнуляется, обучение больше не повторяется. Если не успеть — обучение начинается заново.

Панель подсказок появляется автоматически после `start`; скрыть и снова показать: `hints`. Справа снизу — ползунок общей громкости и плеер: кнопки `‹`/`›` переключают трек, рядом показано его название. В игре после окончания трека плейлист сам переходит к следующему, трек меню и музыка катсцены играют по кругу. Ручной выбор трека сохраняется при смене меню/геймплея. Трек меню есть только в меню — во время игры он скрыт из плеера и не играет.

Справа снизу мигают значки-напоминания: письмо — есть непрочитанное письмо, зелёный человечек — есть свободный слот в команде, красный человечек — в команде что-то случилось (открой `team`), зелёная стрелка — есть нераспределённые очки навыков. Слева сверху после `start` показаны значки анонимности и сети.

Баланс и строка обучения находятся внизу, рядом со строкой ввода. Меню `shop`, `farm`, `team`, `skills`, `status`, `targets` обновляются после покупок и действий — старый список заменяется актуальным.

## Сохранения

Прогресс автоматически лежит в `localStorage` браузера, а не в папке игры. Если заменить файлы игры на новую версию в той же папке и открыть её в том же браузере, сохранение останется. Ник хранится отдельным ключом и не сбрасывается вместе с прогрессом.

Для страховки есть переносимые сохранения:

- `export` — сохранить файл `r00tkit-save-*.json` (в Chrome/Edge можно выбрать папку, иначе файл скачается).
- `import confirm` — загрузить файл сохранения. Можно просто перетащить `.json` в окно игры.
- `saves on` — в Chrome/Edge подключить авто-бэкап. Браузер откроет выбор папки: выберите `Документы` (Documents), игра сама создаст внутри `3percentGames` и будет писать `Documents\3percentGames\r00tkit-save.json`. Разрешение спрашивается один раз; дальше файл обновляется при каждом сохранении. `saves now` — записать сразу, `saves off` — отключить.

Авто-бэкап в папку работает только в браузерах с File System Access API (Chrome/Edge) и требует разрешения. В Firefox/Safari используйте `export`/`import`. Если игра открыта по `file://`, браузер может считать разные пути разными хранилищами — тогда переносите сохранение через файл.

## Основные команды

```
start            начать / продолжить
help             список команд
status, st       состояние
hack [название]  взлом
targets          цели текущего уровня
mail             почта
mail clear       очистить почту (вложения сохраняются)
open choice.exe  запустить вложение из почты
menu             главное меню (после финала)
shop             магазин улучшений
buy <название> [n]  купить улучшение
buy rig [n]      купить майнинг-риг
rig              меню майнинг-фермы
team             команда: состав, слоты
team list        свободные хакеры (1–4)
team invite <id> пригласить хакера
team kick <id> confirm  выгнать хакера
skills           навыки
learn <название> [n]  вложить очки (learn * — все)
move             инфо о переезде
move next        переехать
cool             сбросить нагрев
save / load      сохранение
saves            авто-бэкап в 3percentGames
export / import  файл сохранения
hints            панель команд вкл/выкл
reset            сброс (reset confirm)
```

Есть русские алиасы: `статус`, `взлом`, `магазин`, `купить`, `ферма`, `переезд` и т.д. Короткий алиас статуса — `st`.

На каждом уровне доступно по 4 цели взлома. `targets` показывает только текущий уровень. `hack` без цели выбирает следующую по кругу, `hack <название>` — конкретную.

Раз в 20–30 взломов посреди работы срабатывает защита: экран очищается, взлом замирает, а терминал красным выдаёт предупреждение и зелёным — случайную seed-фразу из 6 слов. Нужно повторить её целиком и нажать Enter за 15 секунд. Первый раз даётся 30 секунд, чтобы успеть прочитать; все следующие — 15. Ошибка отнимает 2 секунды, а если не успеть — взлом срывается, штраф 2× от суммы взлома и +12% нагрева. За успешное подтверждение награда за взлом увеличивается на 25%. Фраза каждый раз новая и не повторяется.

При балансе $500 000 происходит сюжетное событие с хакером unknown. В начале катсцены музыка останавливается, играет `glitch`, затем включается отдельный трек `500k_scene` (в плеере он не показывается, плеер на время катсцены скрыт). После неё вся почта очищается, остаётся одно письмо с вложением `choice.exe`.

## choice.exe

Запуск: `open choice.exe` (алиасы `run`, `открыть`). Открывается отдельное окно в стиле консоли Windows — не зелёный терминал игры. Окно нельзя закрыть, не сделав выбор; пока оно открыто, игра на паузе. После выбора окно 3 секунды не реагирует, затем закрывается любой клавишей или кликом.

Три варианта:
1. Присоединиться к unknown — игра продолжается, приходит письмо с инструктажем (`tone = ally`).
2. Лечь на дно и выйти — финальный экран. Старый сейв не удаляется: `menu` — вернуться в главное меню, `reset confirm` — начать заново. Повторный `start` снова показывает финальный экран.
3. Вскрыть choice.exe — проверка: повторить контрольную строку за 15 секунд. Успех: флаг `backdoor`, нагрев +15%, редкая цель через несколько секунд, письмо от unknown (`tone = rival`). Провал: нагрев +25%, издевательское письмо, повтора нет.

Выбор сохраняется в сейве (`choiceOpened`, `choiceResult`, `choiceAt`, `tone`, `flags`). Второй раз окно не открывается. Старые сейвы со `story > 0` получают письмо `choice.exe` при загрузке, если его нет и выбор ещё не сделан.

## Глава 2

После сюжета на $500 000 остаётся глава 1. На $10 000 000 приходит письмо «НУЖНО БЕЖАТЬ» с вложением `data.txt`. Открой его командой `open data.txt`: внутри координаты `21.919520, -71.94013`, билет и QR. Дальше выбор: `1` — сбежать (старт главы 2), `2` — не слушать unknown (тюремный финал: 18 статей, 99 лет).

В главе 2 весь прогресс главы 1 стирается. Ты скрываешься в тихой комнате и работаешь с `cyberleek`. Вместо денег и нагрева — три ресурса внизу экрана:

```
N3X: 12.4   Points: 3   VIRUS: 5 / +0.2 points/s   info [||||||||||......] 30/100
```

- **N3X** — крипта NeXus. Тратится на сети VIRUS.
- **Points** — очки навыков (SP). 100 VIRUS-поинтов = 1 SP.
- **VIRUS** — количество заражённых ПК и скорость накопления VIRUS-поинтов.
- **info** — прогресс текущего дела.

### Дела

Цепочка: `s1mka → wh33ls → sc3me → c0p → v01ce → 4non`.

- `case` — текущее дело;
- `dig` — копать (кулдаун, 10% провал, шанс находки N3X);
- `expose` — сдать дело при 100%.

Каждое дело требует всё больше `info`. После `expose` приходит обязательное письмо от `cyberleek`; пока оно не прочитано, `dig`, `expose`, `virus buy` и `skills` заблокированы.

### VIRUS

- `virus list` — сети, цены, прирост ПК и points/s.
- `virus buy <id>` — купить сеть за N3X.
- Пассивно капают VIRUS-поинты; 100 поинтов автоматически превращаются в 1 SP.
- Иногда сеть сгорает: теряется часть ПК и скорости, нужно докупать.
- В обучении VIRUS капает в 5 раз быстрее.

### Skills

- `skills` — список;
- `skills buy speed|depth|accuracy|autodig` — потратить SP.

Speed ускоряет dig, Depth даёт больше прогресса, Accuracy повышает шанс находки, Autodig делает пассивный dig.

### Darknet

- `darknet` — побочные заказы, горячие заказы и слухи;
- `darknet take <id>` — взять заказ;
- `dig side` / `expose side` — побочное дело.

Побочные заказы дают N3X и не мешают сюжету. Горячие заказы живут 5–10 минут.

### Почта

- `mail` — список писем;
- `mail read <id>` — открыть.

Письма не удаляются. При открытии на 3 секунды блокируется ввод, затем письмо закрывается любой клавишей. Если письмо обязательное и не прочитано, основные действия заблокированы.

### Команды главы 2

```
case                  текущее дело
dig                   копать основное дело
dig side              копать побочное
expose                сдать дело при 100%
expose side           сдать побочное
darknet               заказы и слухи
darknet take <id>     взять побочный заказ
virus                 меню VIRUS
virus list            список сетей
virus buy <id>        купить сеть за N3X
skills                навыки
skills buy <id>       потратить SP
mail                  почта
mail read <id>        открыть письмо
help                  справка
reset confirm         начать главу 2 заново
```

Старые `hack`-фарм, `farm`, `rig`, `team`, `move`, `heat/cool` в главе 2 отключены.

### Сохранение

Глава 1 хранится отдельно в `S.ch1`, глава 2 — в `S.ch2` внутри `r00tkit_save_v2`. Старый сейв `garage_idle_v1` мигрирует автоматически: ник сохраняется, старая глава 2 перезапускается в новом формате. `reset confirm` в главе 2 сбрасывает только главу 2 и не возвращает в главу 1.

## GitHub и версии

Репозиторий: `https://github.com/lolerfttt/R00TKIT` (приватный).

Правило: **все изменения игры сразу отправляются на GitHub**, чтобы ничего не потерялось и не сломалось. Не оставляй готовые правки только на компьютере.

После каждой законченной правки:

```bash
git add .
git commit -m "v0.5: короткое описание изменений"
git push
```

Нововведения помечаются версией в сообщении коммита и тегом:

```bash
git tag -a v0.5 -m "v0.5: короткое описание"
git push origin v0.5
```

Схема версий:

- `v2.0` — текущая версия с переработанной главой 2;
- каждое заметное нововведение (новая механика, экран, сюжетный фрагмент) — следующая версия: `v2.1`, `v2.2` и так далее;
- мелкие багфиксы и правки текста можно коммитить без нового тега, но всё равно с `git push`;
- один коммит — одна законченная правка. Не смешивай несколько разных фич в один коммит.
